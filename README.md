# jikasei

当前版本：`1.31.1`。

![jikasei](preview.png?v=2)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗与图标资源都自带。

本仓库由 [mghts](https://github.com/mghts/monitor-theme-jikasei) 维护，fork 自
[akanotanin/monitor-theme-jikasei](https://github.com/akanotanin/monitor-theme-jikasei)。
保留原作者署名及上游 MIT 版权与许可，在原主题基础上持续改进。

## 安装

当前安装与更新来源为 [mghts/monitor-theme-jikasei](https://github.com/mghts/monitor-theme-jikasei)。

在 Monitor 后台的主题 GitHub 安装入口输入 `https://github.com/mghts/monitor-theme-jikasei`，
安装最新正式 Release。已经使用原作者仓库的实例，也需要从此地址安装一次，之后主题卡片上的
GitHub 更新会从本 fork 获取新版本。

手动安装：从本仓库的 [最新 Release](https://github.com/mghts/monitor-theme-jikasei/releases/latest)
下载 `theme.tar.gz`，上传至探针后台。Release 同时提供 `theme.tar.gz.sha256`，可用
`shasum -a 256 -c theme.tar.gz.sha256` 校验下载文件。

安装包中的 `theme.json` 与页脚源码链接指向本 fork；原作者仓库用于追溯来源。

## 预览
![节点地球](preview-globe.png?v=3)

列表页顶部那颗正射投影的地球（默认开着；站长在主题设置里关掉＝整块关，顶栏那枚图标也一起
收起；开着时访客可以自己关，选完记在他自己的浏览器里）。

- **地球本身**：79 个环、1483 个点的海岸线（主题自带，不连任何外部服务），每 30° 一条经纬网、
  一条会缓慢扫过的经线，背面的大陆一概不画；拖拽可以转它（横向 0.48°/px、纵向 0.36°），
  默认自己慢慢转，可用「暂停旋转 / 开始旋转」控制；钉住某个地区后就停下，点击「开始旋转」
  可继续转动并保留地区筛选。地球和扫掠经线共用播放时间，恢复时从暂停位置继续；
  切到 2D、拖动、滚出视口或标签页在后台时也暂停计时。系统开了「减弱动态效果」则不转。
- **3D / 2D 切换**：默认显示 3D 地球，也可切到同配色的 2D 世界地图。两种视图使用相同的节点、
  地区、台数和详情入口；2D 保持静止，使用等距矩形投影，支持缩放和拖动平移。
  2D 不展示两侧节点名称和引线，完整世界按可用空间铺开，保持 2:1 比例；悬停节点标记可查看名称，
  点击可进入节点详情。两种模式都不再绘制节点之间的装饰连线。
  模式与旋转偏好只保存在访客自己的浏览器里，刷新后保留；首次访问或无效记录仍显示旋转的 3D。
- **手动缩放**：范围为 50%–150%，滑条每档 5%，缩小、放大按钮每次调整 10%，点「重置」恢复 100%。
  缩放后仍可拖拽旋转、选择地区；比例只保留在当前显示的地球中，重新进入或刷新页面恢复默认。
  标签采用独立字号，长名称按可用空间省略；桌面两栏布局中，地图在可用区域垂直居中。
- **底部控件**：3D / 2D 与旋转按钮位于地图左下角，缩放控件位于右下角，同一行排布，
  为地图留出更多显示空间。窄屏按钮使用简短文字与图标，控件独立占位，不遮住节点标签。
  极窄屏收起加减按钮，仍可使用滑条与重置调整比例。
- **针：小队一台一枚，大机群一个地区一枚**：落点按国家算，名字里认得出城市就按城市。
  使用接近原版大小的柔光信标：在线为绿芯绿圈，离线为红芯红圈并带短横线，部分离线为绿芯红圈；
  核心直径固定为 6.4px，取消黑色描边，只有在线光晕轻微呼吸，系统减弱动态效果、后台或离屏时静止。
  3D 与 2D 使用同一套标记，悬停可查看状态及聚合节点的在线、离线台数。
- **右侧地区列表**：按地区分组与台数，点一行＝地球飞过去并钉住，同时**下面那张列表只留该地区的机器**；
  再点一次、或点「全部」＝取消筛选，按旋转偏好决定是否继续自转。城市按节点名与分组识别并核对国家码，
  未确认城市时显示国家或地区全名，不再显示裸的两位代码；国家级坐标不冒充已确认的城市。
  切分组标签时地球与地区列表跟着变（与概览卡片同一口径）。
- **窄屏**：与桌面同一档（海岸线、扫掠、连线都在），圆盘按窄屏比例排布；拖动只接管横向，
  竖划仍然是滚页面。
- **顶栏入口图标（自动探测，没有设置项）**：本站 `/chicken/` 上装了那座 3D 小鸡农场才出现，
  没装就什么都不显示、不占位（判据是「那条接口回的是不是 JSON」，不是状态码——hub 对未知路径
  会回落到主题首页并回 200）。装了就有，不必配；也没有「指向别处」或「关掉」这两档。

## 访客自己换卡片形态

顶栏那枚方形图标（列表页才有）点开是五档：**经典 / 简约 / 延迟 / 详细 / 紧凑**，与后台设置里那五档
一一对应，选中的打勾、站长在后台设的那一档标「默认」。

- **选完立刻生效、刷新还记得**，但只记在访客自己的浏览器里（localStorage），**不写 hub** ——
  后台那格是「默认看到哪种」，访客自己的偏好不该改到全站。
- 选成**与后台设置相同**的那一档时，记录会被删掉 ＝ 回到「跟着站长的设置走」；这样站长以后改默认，
  没自己挑过的访客也会跟着变。
- 认不出的存值（旧版本、手改）一律当作「没选过」，退回后台设置的那一档；旧名 `detail` 会迁到「延迟」。
- 点别处或按 `Esc` 收起。只影响列表页：详情页不受它影响，也没有这枚菜单。

## 延迟图显示选项

后台「主题设置 → 节点信息 → 延迟曲线样式」统一设置首页卡片、延迟浮层、紧凑展开与节点详情的
默认线形，共四档：

| 样式 | 连接断点 | 平滑曲线 |
|---|---|---|
| 折线，保留断点（默认） | 关 | 关 |
| 连续折线 | 开 | 关 |
| 平滑曲线，保留断点 | 关 | 开 |
| 连续平滑曲线 | 开 | 开 |

旧站点没有保存这一项，或取值无效时，仍使用默认的断点折线。
详情页的「网络延迟」页签和紧凑列表展开行保留以下独立开关。「连接断点」与「平滑曲线」的初始值
跟随站点默认，访客临时切换线形后，同一会话内的首页卡片、浮层、紧凑展开与详情同步；
点「恢复默认」或刷新页面恢复站点默认。

- **连接断点**：连接缺少有效延迟样本的曲线区间，仅改变显示；原始丢包率与「无响应」信息仍保留，
  连线不代表缺口内实际测得了连续数据。
- **平滑曲线**：使有效样本之间的连线更平顺，保留有效样本并限制过冲。
- **削峰**：默认关闭，独立过滤局部异常峰值，可与上述两项分别搭配。

## 关于备注

备注有**两处来源**，都在 hub 后台的节点里填：

1. **「公开备注」**（hub ≥ 1.3.2，单行 ≤100 字）——写给访客看的那条，随公开视图下发，匿名访客也拿得到；
2. **「私有备注」**——写给自己的那条，只下发给登录的管理员，
   访客拿不到。

**两边写法一致**：逗号分隔就是多枚，一枚一枚各自成小卡片（半角 `,` 与全角 `，` 都认，两侧空白削掉、
空片段丢掉）；私有那条多一手「按换行也拆」（hub 对它没有单行约束，常有人把几件事分行写）。

**两处合并显示**：卡片与详情页摊的是**私有 + 公有**合成的一串——私有在前（带锁 + 描边，只有登录的
自己看得到），公有在后。访客那边 hub 不下发私有备注，所以同一个位置他们看到的只有公有那几枚。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不落副本）：

**站点图标不在这一页**：hub 1.4.0 起由面板的「设置 → 站点图标」管 —— 选好之后浏览器标签页、
书签、手机主屏幕与顶栏那枚圆形站标一起换，**换主题也保留**；主题自带的那份只在没设图标时兜底。

| 分组 | 设置项 | 默认 | 说明 |
|---|---|---|---|
| 列表与卡片 | 节点地球 | 开 | 列表页顶部那颗会自转的球（每台机器一枚针、一条引线连到左右两摞地区标签，旁边一条一条列着地区）。关掉＝**整块不渲染**（顶栏那枚地球图标也一起收起，页面上不留一个点了没落点的按钮），版面更安静、也不再去算岸线。开着时访客可以在顶栏那枚图标上自己关/开，以他的为准（只存在他自己的浏览器里）；他再点回与这里相同的那一档，就重新跟着这里的设置走。 |
|  | 列表页顶部 | 两个都显示·概览卡片价值版 | 列表页顶部显示什么，六选一：**都不显示**／**只显示分组标签**／**只显示概览卡片·原版**／**只显示概览卡片·价值版**／**两个都显示·概览卡片原版**／**两个都显示·概览卡片价值版**（默认）。分组标签 = 那一行「全部 / 各组 / 未分组」，节点本来就没有分组时无论如何都不显示；概览卡片 = 那行统计卡片，数据都取自节点列表本身、不多发请求，**数字跟着分组标签选中的那一档走**（选「全部」时就是全站；不存在标签行时自然一直是全站），只有实时网速那张下面那条走势线画的是访客打开页面后的实时速率，刷新页面就从空的重新攒。原版是四张卡片各一块读数（节点在线数、最忙节点、今日与累计流量、全站实时网速）；月度预算剩余价值版把前两张各排两块读数——第一张是「月度预算」与「剩余价值」，第二张是「节点」与「最忙节点」（两块分居卡片两端）。**月度预算** = 各节点价格按计费周期摊到每月后相加；**剩余价值** = 已付但没用完的那一段（价格 × 剩余天数 ÷ 周期天数）；两者都按主题里写死的固定汇率折成人民币显示（因此写「≈」，口径与汇率在悬停提示里），一次性买断、没填价格、没有到期日的机器不计入。 |
|  | 卡片形态 | 详细 | 卡片长什么样：「经典」卡片底部是 2×2 四格——速率一行、总量一行（都是文字箭头 ↓ ↑，第一行用前景色、第二行弱化），上面一条分隔线；卡面不含延迟，延迟收在卡片右上角那枚信息图标的浮层里（点开才去取）；「简约」把底部收成一行两段——左边实时速率、右边累计总量，读数窗另换一套视觉——表名改用前景色（附加信息仍弱化）、进度条压到 4px、底注降到 11px、名字加粗一档、读数格行距收紧，同样不含延迟；「延迟」底部与「简约」同一行两段、下方带三网延迟；「详细」在延迟之上再添在线时长、价格与到期；「紧凑」换成一行一台的表格（名称 / 系统 / 在线 / 剩余 / 价格 / 负载 / 网速 / CPU / 内存 / 硬盘 / 流量，列随屏宽收放、每个指标带一条细进度条），一屏能排下两三倍。**紧凑形态点一行就地展开**——展开行里挂的是那张带量程按钮与削峰开关的延迟图（不跳详情页），要去整页详情点展开行右上角的入口。量程按 hub 的**保留天数**生成：1 / 6 / 24 小时一直都在，够得着才多出 7 天、30 天与保留天数本身（最多六枚）；保留天数超过 7 天的窗口读的是 hub 的小时汇总，坐标轴只写到日。五种形态配色与读数口径一致，只有信息多少与排布不同（进度条统一是**前景色的 70%**：一页几十台时不会连成一片黑条，低负荷的短条也还看得出来）。**这里选的是访客默认看到的那一档；访客可以在顶栏那枚菜单里自己换**（见「访客自己换卡片形态」）。 |
| 节点信息 | 备注显示位置 | 卡片与详情页都显示 | 备注小卡片摊在哪儿，四选一：**卡片与详情页都显示**（默认）／**只在卡片上显示**／**只在整页详情里显示**／**都不显示**（备注整个关掉，hub 里填了也不摊）。取值不认识（老站点配置、手改库）→ 按默认处理，备注不会凭空消失。它下面那行灰字就是备注的用法说明（填在哪儿、逗号＝多枚、留空不显示）。 |
|  | 显示的延迟线路 | 空（自动） | 卡片「三网延迟」与详情页延迟图上显示哪几条线路，一行一个 ping 任务名（最多三条）；留空按后台顺序自动取前三条。名字对不上的行会被跳过。 |
|  | 延迟曲线样式 | 折线，保留断点 | 四选一：**折线，保留断点**（默认）／**连续折线**／**平滑曲线，保留断点**／**连续平滑曲线**。首页卡片、浮层、紧凑展开与节点详情共用默认线形；只影响显示，保留原始丢包与无响应数据。详情或紧凑展开的开关可临时切换，同一会话内同步首页；点「恢复默认」或刷新恢复站点默认。 |
| 外观 | 主题模式 | 随系统设置 | 整站的明暗，四选一：**随系统设置**（默认，跟访客的 `prefers-color-scheme` 走）／**随北京时间自动切换**／**亮色**／**暗色**。「自动」按**北京时间 19:00–07:00 用暗色、其余用亮色**（中国不实行夏令时，固定 UTC+8），页面开着跨过这两个点也会自己换过来（每分钟问一次钟点）。访客点过顶栏那枚太阳/月亮图标就以他的为准（同样只存在他自己的浏览器里，点回与这里相同的一档＝重新跟着这里走）。 |

## 开发与发布

每完成一批修改，发布一个新版本。缺陷修复递增 patch，新增兼容功能递增 minor，破坏兼容性的改动
递增 major；版本采用 `x.x.x`，Git tag 使用同样的数字格式。

1. 同步 `package.json`、`theme.json` 与 `package-lock.json` 中的版本号。
2. 在新的空临时副本中执行 `npm ci`、`npm run lint`、`npm test`、`npm run check` 和
   `npm run package`，完成构建、打包及包内容校验。已有 `dist/` 或发布产物应先保留备份，禁止直接清空。
3. 提交修改，推送 `master` 和对应的数字 tag 至本 fork。
4. 发布 GitHub Release，提供可安装的 `theme.tar.gz`、版本化主题包和各自的 SHA-256 校验文件，
   并确认 Release 资产可下载。

发布主题包后，线上探针的安装或升级由用户决定；发布流程不自动修改线上探针。
